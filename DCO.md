## How This Is Used in This Project

Contributors indicate acceptance of this certificate by adding a `Signed-off-by` line to each commit message:

```
Signed-off-by: Your Name <your.email@example.com>
```

This can be added automatically by committing with:

```
git commit -s
```

No additional agreement, form, or signature is required.
